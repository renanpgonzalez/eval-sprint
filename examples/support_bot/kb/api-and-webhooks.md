# API and webhooks

## Availability
The API and webhooks are available on the Pro and Team plans.

## API keys
Create and revoke API keys at Settings > Developers. Keep your keys secret, because anyone with a key can act on your account.

## Rate limits
The API allows 60 requests per minute per account. Requests above the limit receive a 429 response, so wait a moment and retry.

## Webhooks
Add a webhook endpoint at Settings > Developers to be notified about events such as invoice.sent and invoice.paid.
